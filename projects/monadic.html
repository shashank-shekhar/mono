A VS Code extension for creating blogs from markdown files

Monadic

Monadic is a VS Code extension that makes it easy to create and manage blogs using markdown files. It supports GitHub Pages publishing, custom themes, and a rich set of features.

Features

  • GUI-based blog management from VS Code
  • Markdown and MDX support with TOML frontmatter
  • Liquid templating engine
  • Built-in theme system
  • GitHub Pages publishing
  • Search functionality with Fuse.js
  • Multi-folder content organization

Tech Stack

  • TypeScript
  • Bun.js for builds
  • Preact for dashboard UI
  • Liquid for templating
