# Demo Theme

A sample theme built for the Monadic blogging platform. This theme demonstrates the theme system capabilities including dark mode, custom fonts, and responsive layouts.

## Design Goals

- Clean, minimal aesthetic
- Excellent readability
- Mobile-first responsive design
- Dark mode support

## Components

The theme includes layouts for posts, pages, archives, and collection items.
